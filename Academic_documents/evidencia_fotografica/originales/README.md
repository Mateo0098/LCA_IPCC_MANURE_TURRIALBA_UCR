# Fotografías originales del TFG

Esta carpeta contiene fotografías originales de campo y laboratorio del TFG.

- Conservar los archivos originales sin edición ni renombrado innecesario.
- Las fotografías se inventariarán y catalogarán posteriormente.
- No inferir información científica únicamente a partir de una fotografía sin respaldo del investigador o de otra fuente documental.
